## 🚀 How to Use

### Windows Quickstart
1. Double-click `launch-brain.bat` OR
2. Navigate to the folder and run:
   ```cmd
   python ableton_brain.py
   ```

### Web GUI Access
1. Open `gui.html` in any modern browser
2. Click tabs to explore:
   - 🎵 **Artists** - View detailed artist profiles
   - 🔧 **Engineers** - Top EDM recording engineers
   - 🎛️ **Techniques** - Production methods and workflows
   - 📚 **Resources** - FTP sites and GitHub archives
   - 📊 **Stats** - Database statistics
